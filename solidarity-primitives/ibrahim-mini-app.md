# Ibrahim Mini App

## Overview
Ibrahim Mini App is a Farcaster-based mini application for charitable donations, part of the Solidarity Primitives ecosystem designed to enhance community engagement and facilitate direct support for humanitarian causes through decentralized social platforms.

- **Automatic CI/CD Pipeline**
  - Automated testing on every pull request
